Projects & Datasets

Open Resources

Datasets, tools and GitHub repositories built by HausaNLP for the research community.

HuggingFace

Datasets on HuggingFace

Freely available datasets for training and evaluating NLP systems on African languages.

AfriSenti-Twitter

Multilingual Twitter sentiment corpus covering African languages. Used in SemEval-2023 Task 12.

View on HuggingFace →
NaijaSenti-Twitter

Nigerian Twitter sentiment for Hausa, Yoruba, Igbo and Pidgin. Lacuna Fund supported.

View on HuggingFace →
HausaVG

Hausa Visual Genome for multi-modal English-to-Hausa machine translation, created by professional translators at BUK.

View on HuggingFace →
HausaVQA

Visual question answering dataset for Hausa — enabling vision-language research in low-resource settings.

View on HuggingFace →
Naija-Lex

Lexical resource for Nigerian languages supporting morphological analysis and sentiment lexicons.

View on HuggingFace →
Naija-Stopwords

Curated stopword list for Nigerian languages for text preprocessing.

View on HuggingFace →
